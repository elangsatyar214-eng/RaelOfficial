## 🚀 Cara Menaruh ke GitHub & Mengaktifkan GitHub Pages (Gratis & Mudah):

### Langkah 1: Buat Repositori Baru di GitHub
1. Buka [github.com](https://github.com) dan login ke akunmu.
2. Klik tombol hijau **New** (Buat repository baru).
3. Beri nama repositori, misalnya: `anniversary` atau `two-universes`.
4. Pilih **Public** (karena GitHub Pages gratis membutuhkan repositori publik).
5. Klik **Create repository**.

### Langkah 2: Upload File Website
1. Di halaman repositori yang baru dibuat, klik **"uploading an existing file"** (atau gunakan terminal git jika terbiasa).
2. Drag & drop seluruh isi folder ini (`index.html`, `style.css`, `script.js`, dan folder `assets`) ke GitHub.
3. Klik tombol hijau **Commit changes**.

### Langkah 3: Aktifkan GitHub Pages
1. Di repositori GitHub-mu, klik tab **Settings** (di menu atas repositori).
2. Di menu samping kiri, klik **Pages**.
3. Pada bagian **Build and deployment > Branch**, ubah dari `None` menjadi **`main`** (atau `master`), lalu klik **Save**.
4. Tunggu sekitar 1–2 menit, refresh halaman Settings > Pages tersebut.
5. Link websitemu akan muncul di bagian atas:
   👉 `https://username-kamu.github.io/nama-repo/`
6. Bagikan link tersebut ke Rachel sebagai kejutan manis! 🖤✨
