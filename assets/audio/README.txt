PANDUAN MUSIK BACKGROUND WEBSITE ("INI ABADI" - PERUNGGU)
========================================================================

Untuk memasukkan lagu background music website:

1. Letakkan file MP3 di folder ini (assets/audio/):
   - assets/audio/ini-abadi.mp3  <-- (Nama rekomendasi)

Nama file lain yang juga otomatis dikenali dan didukung:
- ini-abadi.mp3
- Ini Abadi.mp3
- perunggu-ini-abadi.mp3
- Perunggu - Ini Abadi.mp3
- perunggu-ini-abadi.MP3
- assets/audio/songs/ini-abadi.mp3

Catatan:
- Pastikan format file adalah .mp3
- Jika file belum dimasukkan, website tetap otomatis memutar melodi synthesizer romantis yang syahdu!
